# v0.31–v0.38 — analysis claims and verifiable bundles

This slice makes a completed analysis inspectable without pretending that structure equals truth.

- ordered immutable claims with explicit kinds and qualifications;
- links only to source fragments actually examined and human context explicitly recorded as used;
- append-only human review that never rewrites the original claim;
- claim lineage across an explicit reanalysis;
- recorded clarification impact on later claims;
- deterministic core manifest, portable JSON export and SHA-256 integrity verification.

The manifest deliberately excludes later human review and other append-only steering events so those events can arrive without falsifying what the sealed analysis originally contained.
