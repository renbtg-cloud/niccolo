# Development history (not the product introduction)

Niccolò's development records are retained for traceability, but are deliberately separated from the repository's public entry point. Historical milestones and checkpoint documents are **not current promises or independent proof that a feature works**.

- **[Progress](progress/)** — WORK_PROGRESS and TEST_PROGRESS logs, including dated/versioned results.
- **[Checkpoints](checkpoints/)** — older snapshots of API, analysis, reasoning and storage design.
- **[Planning](planning/)** — proposals, deferred scope and implementation plans.
- **[Editorial](editorial/)** — README editing and documentation-review notes.

Start with [the public README](../README.md) and [documentation guide](../docs/README.md). The authoritative implementation is the code, migrations and current passing validation, not a milestone count.
