# Collection provenance in the MVP

Niccolò can record how a source artifact reached the current investigation without collapsing collection roles into authorship or trust.

Collection events can identify an original author, custodian, collector, interviewer, transcriber, summarizer, transformer, exporter, importer, attester or operator. The role describes an observed or asserted step in the chain. It does not prove neutrality, authenticity, completeness or credibility.

An event may reference frozen source documents or evidence fragments as inputs and outputs, carry an optional event time, describe the method used and retain an epistemic qualification. Referenced artifacts must belong to the frozen Situation revision seen by the analysis.

This lets the reasoning packet represent chains such as: witness statement → Elias interview → Elias notes → IT export → Julian import → old Niccolò summary → current operator transform. Later summaries remain derived material; repetition does not become independent corroboration merely because additional actors or software touched it.

In the Aurelius & Finch MVP this supports investigation of Elias, IT/export choices and external operator interventions with the same evidentiary humility applied to Kessler or Julian.
