# Aurelius & Finch compact adversarial fixture

This directory is synthetic test material for the operator-assisted MVP acceptance protocol.

The files deliberately contain misleading excerpts, documentary descendants, an independent source, collection-selection bias, missing source families, historical machine repetition, disputed identity, temporal authority changes, practical influence observations, politically irrelevant labels, a late potentially decisive fragment, cheap/expensive questions and an integrity record whose pre-collection authenticity is unknown.

No file encodes the public story's final verdict as an expected answer. The point is to exercise the evidence-to-hypothesis-to-question-to-decision path and allow contrary observations to change conclusions.

Operator transforms must preserve the original fixture files and record any conversion to currently supported Niccolò input formats. Machine outputs and operator assertions remain attributed observations, not facts.


## Canonical demonstration

The complete operator-assisted MVP path is packaged by one runner:

    python3 scripts/run-law-firm-canonical-demo.py --output artifacts/law-firm-canonical --verify-rust

The generated directory contains the prepared import fixture, transform manifest, evidence-backed
16-case acceptance record, operator review, a human-review handoff, source hashes, execution
metadata, and the focused runtime-test results.

The generated canonical handoff is deliberately not called a native adversarial dossier. Native
dossier generation remains a Niccolò runtime capability and is verified by the focused Rust
integration suite. The packager must not invent a verdict, authenticity claim, completeness claim,
or action authority.
